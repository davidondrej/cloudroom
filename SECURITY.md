# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Report security issues privately using either option:

- **GitHub Security Advisories:** [Submit a private report](https://github.com/davidondrej/cloudroom/security/advisories/new)
- **Email:** [david@cloudroom.dev](mailto:david@cloudroom.dev) (Security lead: David Ondrej, CEO)

Include clear steps to reproduce, affected versions or components, and the expected impact.

## Supported Versions

Security fixes ship on the latest release of the Cloudroom desktop app and `cloudroom-core`. Older versions are not patched.

## Security Overview

See [cloudroom.dev/security](https://cloudroom.dev/security) for our security architecture, trust boundaries, official domains, and known limits, and [cloudroom.dev/privacy](https://cloudroom.dev/privacy) for our privacy policy.
