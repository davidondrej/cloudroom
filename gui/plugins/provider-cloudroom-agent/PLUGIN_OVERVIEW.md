## What you get

- A "Continue with Cloudroom Agent" button on the plan-limit card.

## How it works

Cloudroom Agent runs the Pi coding agent on your computer, with a model Cloudroom hosts. It keeps its own settings, so your own Pi setup is never touched. Pi is installed for you if it is missing.

## Requirements

- Signed in to Cloudroom, with Cloud Credits left. Signing out stops it at once.
